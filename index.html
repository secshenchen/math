1. 基础图形

长方形

C=2(a+b) S=ab 4个直角 对边相等

正方形

C=4a S=a² 4边相等 4个直角
两条对角线相等、互相平分、互相垂直， 并且平分顶角。

平行四边形

C=2(a+b) S=ah 对边平行且相等 对角相等

梯形

S=(a+b)h÷2 中位线=(a+b)÷2
平行的两条边叫上底和下底。 面积等于“上底加下底”乘高再除以 2。

2. 三角形

按角分类

锐角三角形 直角三角形 钝角三角形
三个角都小于90°：锐角三角形。
有一个角等于90°：直角三角形。
有一个角大于90°：钝角三角形。

按边分类

不等边三角形 等腰三角形 等边三角形
等边三角形三个角都是 60°。 等边三角形也是特殊的等腰三角形。

内角和

三角形=180° n边形=(n−2)×180°

三边关系

两边之和＞第三边 两边之差＜第三边
快速判断时，把最长边找出来， 检查另外两条边之和是否大于最长边。

三角形面积

S=ah÷2 a=2S÷h h=2S÷a

3. 等积模型

等底等高

等底等高 → 面积相等
两个三角形底相同， 顶点位于与底平行的同一直线上， 则高相同，面积相等。

等底不等高

面积比=高之比

等高不等底

面积比=底边比

4. 一半模型

三角形中线

中线把面积分成相等两份

两边中点

中位线=第三边÷2 小三角形面积=原面积÷4

顶天立地

三角形面积=平行四边形面积÷2
三角形使用平行四边形整条底， 顶点在对面的平行边上。 两者同底等高。

四边中点

四个中点连成平行四边形 面积=原四边形÷2

5. 风筝模型

风筝模型

S=½ab·sinθ 对角面积乘积相等 S₁×S₃=S₂×S₄

6. 蝴蝶模型

梯形蝴蝶

两翼面积相等 靠两底三角形面积比=底边比²

特殊四边形蝴蝶

对角线互相平分 四个三角形面积相等 每块=总面积÷4
适用于平行四边形。 长方形和正方形都是特殊的平行四边形， 因此同样成立。

7. 鸟头模型

鸟头模型

S=½ab·sinθ 相等角 → sin相等 互补角 → sin相等 对顶角相等
角的正弦值相同时， 面积比就可以转化为夹角两边乘积之比。

沙漏 / 金字塔

平行 → 找相似 边长比=k 面积比=k²

8. 燕尾模型

燕尾模型

共高 → 面积比=底边比 同底 → 面积比=高之比 逐层传递面积比
不要先背图形。 先找哪些三角形共高、同底， 把线段比转化为面积比， 再一步一步传递。

模型题通用判断法

看到中点 → 想 1:1 看到平行 → 想等高 / 相似 看到交点 → 想对顶角 看到对角线 → 想面积分割 看到比例 → 想面积比

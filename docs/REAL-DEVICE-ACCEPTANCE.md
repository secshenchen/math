# iPhone / iPad 真机验收：几何专项练习

当前没有可操作的 iPhone 或 iPad 真机。下列项目均未取得真机结果。桌面离线回归和 Playwright 的移动 WebKit 配置不能证明 Safari 能从“文件”打开 HTML，也不能证明 VoiceOver 的实际播报。

在 **iPhone 和 iPad 各走一遍**。记录设备型号、iOS / iPadOS 版本、日期和被测文件版本。用独立的本地测试账户。如果设备已有正式学习记录，先导出 JSON，避免拿正式账户测试清空或删除。

1. **Safari 与触控。** 在普通 Safari 标签页打开 [练习网站](https://secshenchen.github.io/math/)。注册本地测试账户。展开章节、切换专题、用题号搜索，点上一题／下一题、随机、收藏。iPhone 竖屏和 iPad 竖屏、横屏各看一次；页面及 SVG 应完整显示，软键盘弹出后应能滚动到答案输入框和提交按钮。
2. **答对和答错。** 搜索第 1 题，提交 `84 cm²`，应显示正确；展开解析，应显示文字和答案图。前往第 2 题，提交 `1`，应显示错误，再输入 `24`，确认能判为正确。验证错题筛选及收藏。打开第 3 题输入 `4:25`，确认可判定比例。
3. **Safari 内进度保存。** 在第 1 题和第 3 题留下可区分的记录，例如收藏第 1 题、标记掌握第 3 题。刷新 Safari，再关闭标签页、重新打开同一链接，确认题号、已答、收藏及掌握仍在。导出 JSON，在另一个本地测试账户导入并对照。隐私浏览、不同浏览器、不同文件路径的本地存储可能隔离；用导出和导入来搬运。
4. **飞行模式打开离线文件。** 将本任务提供的 `几何专项练习-离线.html` 保存到“文件”→“在我的 iPhone 上”或“在我的 iPad 上”；确认在联网时文件已完整落盘。打开飞行模式，并手动关闭 Wi‑Fi 和蜂窝数据，再从“文件”点该 HTML。记录实际打开器（Safari、有脚本能力的其他浏览器，或“文件”预览）。若只有静态预览、一直显示加载、无法注册，或分享菜单没有可执行 HTML 的 Safari 入口，**将这一项记为未通过**，写下系统版本和可见提示。若能运行，用测试账户重复步骤 2、3。保持飞行模式开启，关闭打开文件的应用，再从同一路径重新打开并核对进度。如果只有在线 Safari 测通，离线文件仍应记为未验证。这里验证的是已下载的 HTML；飞行模式下直接从网络刷新 Pages 是另一回事。
5. **VoiceOver 实际朗读。** 到“设置”→“辅助功能”→“旁白”打开。每次单指右扫到下一项，双击激活；也可转动转子，通过“标题”或“表单控件”导航。先听登录字段，再在练习区从题目标题开始，记录题号与专题、题干、题图、答题输入、提交、反馈及解析出现的实际顺序。题图应有可辨识的名称，未展开前不应读到隐藏的答案；提交后确认能听到正确或错误，展开后能访问解析文字和答案图。翻题后检查焦点是否落在可理解的位置。可参考 [Apple 的 VoiceOver 手势](https://support.apple.com/en-gb/guide/iphone/iph3e2e2281/27/ios/27)。

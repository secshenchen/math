# math
# 数学｜几何模型专项

这是一个用于几何知识学习与专项练习的网站。

## 📚 学习内容

目前主要包括：

- 长方形与正方形：特征、周长、面积
- 平行四边形：特征、周长、面积
- 梯形：特征、周长、面积
- 三角形分类：按角分类、按边分类、作三角形的高
- 三角形边角关系：内角和、多边形内角和、三边关系、面积
- 等积模型
  - 等底等高三角形
  - 等底不等高三角形
  - 等高不等底三角形
- 一半模型
  - 三角形中的一半模型
  - 平行四边形中的一半模型
  - 梯形中的一半模型
  - 任意四边形中的一半模型
- 风筝模型
- 蝴蝶模型
  - 梯形蝴蝶
  - 平行四边形蝴蝶
  - 长方形蝴蝶
  - 正方形蝴蝶
- 鸟头模型
  - 相等角鸟头
  - 互补角鸟头
  - 对顶角鸟头
  - 沙漏模型
  - 金字塔模型
- 燕尾模型
  - 三角形燕尾
  - 四边形燕尾

## ✨ 网站功能

- 几何公式整理
- 几何图形示意
- 专项练习题
- 答案展开/隐藏
- 知识点搜索
- 随机练习
- 掌握进度记录
- 打印 / 导出 PDF
- 支持电脑、iPad 和手机

## 🚀 使用方法

直接打开：

`index.html`

即可进入几何专项学习页面。

网站采用单文件 HTML 设计，可以离线运行，不依赖外部网站、API、远程 JavaScript 或在线字体。

## 🔒 隐私与离线

核心学习页面可以完全离线运行。

学习数据保存在浏览器本地，不需要上传到服务器。
